## 📋 Descripción del Proyecto
**Viajes Invernales** es una plataforma web desarrollada con enfoque en **arquitectura web modular**. El proyecto consiste en una SPA multi-página que implementa un sistema visual inmersivo basado en **Glassmorphism** y un esquema de navegación avanzado. El objetivo principal ha sido dominar el posicionamiento complejo en CSS y la coherencia visual entre múltiples documentos HTML conectados.

---

## ✨ Funcionalidades Técnicas
* **Arquitectura Multi-página:** Navegación fluida entre diferentes destinos (Austria, Canadá, Japón, Laponia, Suiza) manteniendo una hoja de estilos común y componentes específicos.
* **Layouts:** Implementación de cajas `sticky` que mantienen la información crítica (precios) visible durante el scroll, mejorando la experiencia de reserva.
* **Componentes Interactivos:** Carruseles automáticos y tarjetas con efectos de transformación y hover mediante CSS puro.
* **Formularios de Contacto:** Estructura de inputs con validación de estados y diseño responsivo adaptado mediante `media queries`.

## 💡 Conceptos Técnicos Aplicados (Profundización)

| Apartado | Detalle de la implementación técnica |
| :--- | :--- |
| **Layout** | Uso extensivo de **CSS Grid y Flexbox** para estructuras responsivas que se adaptan automáticamente a diferentes dispositivos. |
| **Posicionamiento** | Aplicación de `position: sticky` en los paneles de reserva, permitiendo que la información relevante siga al usuario sin perder el contexto visual. |
| **CSS Avanzado** | Uso de **Keyframes** para la automatización de animaciones en carruseles y efectos visuales de transición en la galería. |
| **Modularidad** | Separación estratégica de archivos CSS (`estilowebviajes.css` para el layout general, `estilo-destinos.css` para componentes específicos de destinos). |
| **UX/UI** | Aplicación de **Glassmorphism** (fondo difuminado) y paleta de colores contrastada para optimizar la legibilidad en entornos oscuros. |
| **Tipografía** | Integración de Google Fonts externas (`Montserrat`, `Playfair Display`) mediante importación eficiente en el `head` de cada documento. |

---

## 📂 Estructura del repositorio
* `index.html`: Página principal con el buscador y catálogo de destinos.
* `*.html`: Páginas individuales para cada destino turístico.
* `estilowebviajes.css`: Lógica de diseño base, navegación y animaciones globales.
* `estilo-destinos.css`: Lógica específica para componentes de detalle y posicionamiento sticky.
